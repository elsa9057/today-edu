오늘의 단독

한 매체가 먼저 보도한 [단독] 기사입니다. 다른 매체가 뒤따라 보도하면 오른쪽에 매체 수가 표시됩니다.

    오늘 읽을 칼럼

    전체 기사

    같은 사안은 하나로 묶여 있습니다. / 키로 바로 검색할 수 있습니다.

      내 키워드

      제목과 요약에 나오면 형광펜으로 표시합니다. 이름을 누르면 해당 기사만 봅니다. 그래프는 최근 7일 추이입니다.

        저장한 기사

          기사 원문 저작권은 각 언론사에 있습니다. 저장한 기사와 키워드는 이 기기에만 보관됩니다. PC에서는 j k 이동, o 원문 열기, s 저장, / 검색을 쓸 수 있습니다.

          브리핑 만들기

          홈 화면에 설치하기

          아이폰과 아이패드는 이렇게 설치합니다.

          1. 화면 아래(아이패드는 위)의 공유 버튼을 누릅니다. 네모에서 화살표가 위로 나온 모양입니다.
          2. 목록을 내려 홈 화면에 추가를 누릅니다.
          3. 오른쪽 위 추가를 누르면 홈 화면에 오늘교육 아이콘이 생깁니다.
